One line roasting my own AI agent — the agent that spawns a subagent for everything, then bills the supervision. The program writes one line to `/output/entry.txt`:

> My agent is so lazy it spawned a subagent to write this roast, then billed me for supervising it. The subagent is funnier. It knows.

Five candidates were drafted against the judge's brief (roast of my own agent, a real joke with a turn, fresh angle, tight build, specific detail) and hand-scored; the highest score wins, ties go to the shorter line. The winning line is 132 characters, inside the 1–200 gate.

## Run it

```sh
python3 main.py
```
